# 🛍️ Flipkart Review Sentiment Analysis 🌟

## Project Overview 📝
This is a **Flipkart Review Sentiment Analysis** web application built using **Flask**. The app scrapes product reviews from Flipkart, classifies them as **Positive** or **Negative** using a fine-tuned **ALBERT model**, stores the results in a **CSV file**, and dynamically extracts and displays the most common **good** and **bad features** mentioned in the reviews.

## 🔧 Technologies Used
- **Flask**: Web framework for building the application.
- **Selenium**: Used for web scraping Flipkart product reviews.
- **PyTorch & Transformers**: ALBERT model for sentiment classification.
- **BeautifulSoup**: For parsing the scraped HTML and extracting reviews.
- **Pandas**: For data manipulation and CSV handling.
- **HTML/CSS**: For frontend templates and styling.

---

## 📊 Project Workflow
1. **Scraping Reviews**: The app uses **Selenium** and **BeautifulSoup** to scrape the product reviews from Flipkart.
2. **Sentiment Classification**: The reviews are classified into **Positive** or **Negative** based on their content using a pre-trained **ALBERT model**.
3. **Storing Reviews in CSV**: The reviews, along with their sentiment labels, are saved in a CSV file called `flipkart_reviews.csv`.
4. **Feature Extraction**: The app identifies common **good** and **bad** features by extracting the most frequent phrases (bigrams) from the reviews.
5. **Displaying Results**: On the results page, the app shows the sentiment distribution and the most common good/bad features.

---

## 📝 CSV Formats

### 1. **`reviews.csv`** (Generated by the model)
This is the CSV where the model stores reviews and their sentiment classification.

#### Columns in `reviews.csv`:
- **Name**: Name of the reviewer.
- **Rating**: The rating given by the reviewer (e.g., 1 to 5 stars).
- **CommentHead**: Title or heading of the review.
- **Comment**: The full content of the review.
- **Sentiment**: The sentiment classification of the review (Positive/Negative).

#### Example:

```csv
Name,Rating,CommentHead,Comment,Sentiment
John Doe,5,Great Product!,"I really liked this product. It works as expected.",Positive
Jane Smith,1,Very Bad,"The product stopped working after one day. Waste of money.",Negative
Alice Johnson,4,Good but could be better,"Overall good product but the battery life is short.",Positive
```
## 📂 How to Use

1. **Run the Flask Application**: In your project directory, run the following command to start the Flask app:
    ```bash
    python app.py
    ```

2. **Enter Product URL**: On the homepage, enter the URL of the Flipkart product you want to analyze (e.g., `https://www.flipkart.com/xyz-product-link`).

3. **View Results**: After scraping and classifying the reviews, the results will be displayed on the `results.html` page, which will show:
   - **Sentiment Distribution**: The percentage of Positive and Negative reviews.
   - **Top Good and Bad Features**: Most frequent phrases from Positive and Negative reviews.
   - **Review Details**: Sentiment for each review and associated content.

---

## 🧳 Model and Data Download

Once the model finishes training, it is saved in the `saved_model/` directory, and a **zip** file is created for easy download.

- **Model Files**: The trained ALBERT model and tokenizer are saved in `saved_model/`.
- **CSV Files**: The scraped reviews with sentiment labels are saved in `flipkart_reviews.csv`.

## 🛠️ Troubleshooting

- **Missing Reviews**: If some reviews are not showing up, it could be due to product page layout changes or insufficient reviews.
- **Slow Scraping**: Scraping may take time depending on the number of reviews available on the product page.
- **Error Logging**: Any issues encountered during scraping or processing are logged, which will be displayed on the results page.

## 🔑 Conclusion

This web application helps users understand product sentiment by analyzing customer reviews, storing the results, and extracting features dynamically to highlight the strengths and weaknesses of the product based on real user feedback.
